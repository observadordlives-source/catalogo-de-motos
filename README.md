# catalogo-de-motos
Projeto de aprendizado em Java e desenvolvimento backend baseado em uma plataforma para motociclistas.

Documentação dia 1
 
Instalei o intelij uma ide focada em java que basicamente serve para escrever, organizar, executar e depurar programas, e testar na propria plataforma, estou utilizado o Microsoft OpenJDK 21.0.9 (JDK fornece as ferramentar para compilar e executar Java), primeira coisa que eu fiz foi criar um projeto na IDE e escolher essa opção/versão de java para fazer meus projetos, criei uma classe Main no src e criei a base da Main utilizando "psvm", escrevi uma mensagem de teste utilizando sout para saber se estava funcionando, logo após conectei o github ao intellij e testei o fetch que funcionou, para que eu possa fazer tudo diretamente pela ide.
